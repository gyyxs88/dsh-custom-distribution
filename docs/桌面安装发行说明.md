# Desktop rc.5 插件发行包

本项目是非官方插件发行层，使用未修改的 DeepSeek 官方 Windows x64 Desktop
`0.2.1-rc.5`，插件版本固定为 `desktop-v0.2.1-rc.5.1`。该 GitHub Release
标记为 **prerelease**，与旧 Web `v0.5.1` 分开；不要从 Latest 下载旧的
`Install-DSH.ps1` 来安装桌面版。

下载链接在该 prerelease 发布且四项资产上传完成后才可用；本地构建或 mock 下载成功不表示 GitHub 下载已验收。发布者须从明确的 tag 下载资产、核对摘要，再运行下载所得的独立入口。

## 家中电脑第一次安装或从旧版升级

1. 保存工作，正常退出 DeepSeek Harness，包括托盘中的程序。
2. 下载 [Install-Desktop.ps1](https://github.com/gyyxs88/dsh-custom-distribution/releases/download/desktop-v0.2.1-rc.5.1/Install-Desktop.ps1)，右键“使用 PowerShell 运行”。使用当前用户即可，无需管理员、Node、npm 或编译工具。
3. 已安装的精确官方 rc.5 会直接复用。没有 rc.5（包括仍是 rc.2 或 rc.3）时，脚本下载固定的官方签名安装器，验证大小、SHA512 和 Authenticode 发布者后打开官方向导。按向导完成安装，**取消完成页的立即启动勾选**；插件安装结束后再从官方快捷方式打开 Desktop。如果程序已被向导打开，正常退出后再次运行同一脚本。

旧程序升级交给官方安装器。安装脚本不修改 ASAR，不自动停止程序，也不创建另一份服务。程序从当前用户卸载登记及常见安装位置发现，不固定盘符。如果向导选择的路径无法自动发现，使用 `-DesktopPath '<向导选择的程序目录>'` 重新运行即可。

已有 `desktop-v0.2.1-rc.3.1` 插件安装记录时，会核对旧受管插件未被改动，再保存旧包和 receipt 后升级。若这些插件已被修改，先处理冲突；脚本会拒绝覆盖。其他版本的 receipt 不自动迁移。

官方程序固定为 [rc.5 Windows x64 安装器](https://download.deepseek.com/dsh-desk/bin/win-x64/deepseek-harness-0.2.1-rc.5-win-x64.exe)，大小 `289408544` bytes，SHA512（Base64）为：

```text
gu2dH+aTr678c0P8DGAH/h4B1GaWfQIjpsPrLjl/ukLrQIh6DLVq/MhX4FZvJ8o1GCMocOhix6XbLa6KmtjXXg==
```

若右键方式被本机脚本策略阻止，可在保存脚本的目录执行一次：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Desktop.ps1
```

## 离线 ZIP、检查和回退

也可以下载 [固定 ZIP](https://github.com/gyyxs88/dsh-custom-distribution/releases/download/desktop-v0.2.1-rc.5.1/dsh-desktop-v0.2.1-rc.5.1-win-x64.zip)，解压后右键 `scripts\Install-Desktop.ps1`。
ZIP 包含六个固定 tgz、manifest、安装/检查/回退入口和本说明；官方 EXE 由官方站点提供，不放入 ZIP。离线 ZIP 安装要求已安装精确 rc.5，否则仍需联网下载官方程序。

在解压目录运行：

```powershell
# 普通安装检查；不调用模型，不要求重跑适配回归
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-Desktop.ps1 -Action Verify
# 正常退出 Desktop 后回退本发行包的插件改动
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-Desktop.ps1 -Action Rollback
```

若由 rc.3.1 升级而来，Rollback 会恢复旧插件与旧 receipt；**再次启动前须恢复配套的 rc.3 官方程序**。回退不自动降级官方程序，也不回滚官方启动后产生的数据迁移。升级前另行保存配套程序和一致性数据备份，不能只换 EXE。

再次安装同一发行包会核对现有安装并返回 `ALREADY_INSTALLED`；不重复追加 bundle 或许可。
检查覆盖精确官方程序、六包版本/安装文件及兼容许可，不表示真实模型调用或 GenUI 的真实模型端到端验收。

默认使用当前用户 `.dsh` 下的 `profiles/desktop`。原有 `cordis.yml`、
`cordis.patch.yml`、provider、默认模型、会话、pending、凭据和其他 bundle 保留，
不导入任何公司配置。不运行 `npm install`，不从 npm 下载或混入旧核心；六个离线包
直接安装，运行依赖由官方 Host 的模块解析提供。复用包的精确 rc.5 许可通过官方
`setProfileVersionExemption` 合并，保留已有兼容记录。

六包固定如下；GenUI、remote、session-control、codeagents 的 tgz 与上一版逐字节相同，仅通过四项精确 `0.2.1-rc.5` 许可准入，不授予通配版本。

| 包 | 版本 |
| --- | --- |
| `@omdsh-dev/dsh-genui` | `0.9.1-dsh021.3` |
| `dsh-remote-control` | `0.3.3-dsh021.3` |
| `dsh-session-control` | `0.8.5-dsh021.2` |
| `dsh-subagent-code-agents` | `0.2.4-dsh021.1` |
| `dsh-desktop-compat` | `0.2.1-rc.5.1` |
| `dsh-tps-correction` | `0.2.1-rc.5.1` |

每次实际安装前自动保存当前用户/SYSTEM 专属的私有备份，只包含将改动的插件和元数据。
回退先保最新状态，再撤回本安装器添加的依赖、bundle 和许可，恢复被替换的插件；
其后添加的其他设置仍保留。若用户已修改同一受管插件或依赖，自动回退会拒绝覆盖，
保留最新备份供人工处理。安装失败会尝试恢复本轮受管文件，备份始终保留。
回退不降级官方 EXE，也不删除用户数据。不要上传安装器的私有备份或原始 profile。
异常中断后若提示已有安装锁，请保留现场并人工核对上次安装状态，不跳过保护。

## 维护者构建及发布

```powershell
node scripts/Build-DesktopBundle.mjs <空输出目录> <六包所在目录>
```

构建读取 `desktop/releases/0.2.1-rc.5.1/manifest.json` 并核对六包 SHA256，
只打包显式白名单文件。输出 ZIP、内嵌 ZIP SHA256 的独立 bootstrap、
`SHA256SUMS.txt` 与 `publish-assets.json`。不包含源码、构建输入、测试 profile 或凭据。
独立 bootstrap 必须使用构建产物；仓库模板需要显式 `-BundlePath` 或从解压 ZIP 运行。

审查通过后发布独立 tag `desktop-v0.2.1-rc.5.1`，设为 prerelease 且不改 Latest。
上传 ZIP、独立 `Install-Desktop.ps1`、`SHA256SUMS.txt`、`publish-assets.json`。
发布后从这个明确的 tag 下载 bootstrap 和 ZIP，检查校验值再做消费验收。
在收到发布指令前，只生成本地资产，不提交、推送或创建 Release。

PowerShell 入口支持 Windows PowerShell 5.1 和 PowerShell 7，使用 UTF-8 BOM。
普通用户安装检查不启动 Host 或发模型请求。隔离测试使用合成新/旧 profile，
另由官方 Host 检查干净环境插件加载；真实 provider 调用为 0，不声称已验收真实模型
或 GenUI 端到端。本次 rc.5.1 准备未执行真实 NSIS 向导，官方向导下载、安装和完成页操作尚未实机验收；隔离消费测试复用已验证的官方解包程序，独立下载测试只使用本机 mock HTTP。该测试不能代替发布后的 GitHub 资产下载验收。
