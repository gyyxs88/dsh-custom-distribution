# 官方优先，插件补充

基线：DeepSeek Harness 0.1.5-rc.2，发行版 0.5.0。官方功能拥有默认入口；插件只补已经核实的缺口。每次升级先核对官方实现，再决定保留差异，不以“旧版有此补丁”为保留理由。

| 功能 | 默认归属 | 插件保留边界 |
| --- | --- | --- |
| 文件／目录引用 | 官方 file-reference、file-reference-local 和 ui-reference | dsh-at-file 从默认 bundles 撤下；仅保留旧制品与设置，显式选择旧过滤器时才恢复，不与官方选择器叠加 |
| HTTP 代理与 loopback 直连 | 官方 dsh-http-proxy | 启动器不设置 NODE_USE_ENV_PROXY，不改写 NO_PROXY；保留调用者原环境 |
| 消息来源显示 | 官方消息 UI | 仅兼容旧插件历史来源格式，不重建显示层 |
| DSH 子代理、父子消息与当前会话定时 | 官方 subagent、send_message、schedule | Session Control 只负责其它普通会话、跨 Workspace、批量操作、持久回报与受管审批 |
| Codex／Claude Code／ACP 一次性委派 | 当前安装且权限、模型、能力匹配的官方后端 | Code Agents 补外部会话续接、steer、Grok、持久运行回报与严格角色；不自动安装官方后端，也不改变调用方的权限 |
| 同工作区团队与任务板 | 已显式启用的官方 Agent Teams | 不自动开启实验功能，不把现有跨项目普通会话迁成同目录 teammate |
| 模型发现与设置 | 官方发现和设置流程 | 仅保留 OpenRouter／OpenCode 实时目录差异、能力／路由扩展及 network_error 分类；官方新功能不再自行重复实现 |
| 文件／HTML 预览 | 官方 Sidebar | GenUI 仅补会话内交互组件，不代替文件预览 |
| Windows 模块加载、服务重启、远端部署 | 官方启动／服务 API 加薄适配 | 保留已复现的 Windows proxy fallback、真实 PID 与认证就绪检查、SSH 部署和可回滚同步 |

## 升级与退役规则

1. 以目标发布标签的源码核对功能、权限、持久化和失败语义。名字相似不代表等价；已安装也不代表该工具已授权可用。
2. 完整覆盖时撤下默认插件入口，优先使用官方。部分覆盖时缩减插件职责并通过正式 API 扩展；不屏蔽或改名冒充官方工具。
3. 每个保留补丁须列出尚未满足的具体能力。上游补齐后，完成相应回归即可撤下；不能为额外偏好无限保留整套重复实现。
4. 切换前备份。保留旧设置、状态与制品；不删除历史，不重复派发已有任务，不自动降权或提权，不把不确定执行换入口重试。
5. 验收默认 profile 只启用官方文件引用、代理请求实际穿过测试代理且 loopback 直连、认证与重启正常、历史可读，之后再发布。

本轮没有重写官方模型设置，也没有把实验性团队或外部一次性后端强制替换为不等价的跨项目/持久代理流程。
