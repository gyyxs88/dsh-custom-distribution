# 私有数据与迁移

## 干净安装是默认路径

在另一台电脑安装发行版时，只迁移程序能力，不迁移身份和历史。新电脑应自行配置 provider、模型、工作区、SSH Host 和远程项目。

## 哪些内容是私有状态

`data/` 下可能包含：

- `.credentials.yaml` 和 provider 凭据；
- `settings.yaml`；
- 会话消息、压缩记录和附件；
- 工作区绝对路径；
- 审批、定时任务和控制操作记录；
- SSH Host、known_hosts、远程目录、能力 token 元数据；
- 日志、PID 和本机备份。

这些文件可能同时包含秘密、隐私和机器特定绝对路径，不能打进公开 Release，也不能整体提交到 GitHub。

## 如确需迁移

先在两台电脑上停止 DSH，再使用仅在本地保存的加密介质复制经过选择的数据。凭据优先在新电脑重新登录或重新输入；SSH 私钥按原有安全流程迁移；工作区和远程目录应在新电脑重新登记。

发行仓库暂不提供“全量导出并上传”功能，因为这会把最敏感的数据集中成一个高风险文件。未来若增加迁移工具，也必须默认排除凭据、日志和主机密钥，并要求用户显式选择每一类数据。
