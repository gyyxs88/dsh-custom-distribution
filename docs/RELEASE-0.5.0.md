# 0.5.0：官方优先，插件补充

DSH 核心继续精确锁定 0.1.5-rc.2。

- 默认文件／目录引用改用官方实现，旧 dsh-at-file 不再激活；保留制品与历史设置用于显式兼容和回滚。
- 启动器移除 NODE_USE_ENV_PROXY 与 NO_PROXY 注入，代理与 loopback 绕过交给官方 dsh-http-proxy。
- Session Control 0.8.2、Code Agents 0.2.2 明确普通子代理、父子通信及适用的一次性任务优先走官方工具，插件只补缺口。
- 保留现有权限、持久操作与回报、历史来源兼容、远端部署、Windows 模块适配和服务控制。

退役标准及职责归属见 [OFFICIAL_FIRST.md](OFFICIAL_FIRST.md)。这次是默认入口与使用策略调整，不自动启用实验性 Agent Teams，也不把现有持久外部会话替换成一次性官方后端。

验收结果：29 项发行测试通过；官方文件搜索、空格路径、排除目录、代理实请求、loopback 直连与调用者环境恢复通过；干净安装认证、服务重启与原 Cookie 复用、模拟模型设置检查通过。完整 0.4.0 → 0.5.0 → 0.4.0 升级回滚通过，新版不激活旧文件引用插件，回滚后恢复旧版激活列表。

本机已完成切换，浏览器验证官方文件搜索候选与引用插入，随后清空验收草稿且未发送消息。57 个会话可读，切换前 58 个日志文件 SHA-256 不变。两个编排插件的随包 Skill 与注册检查通过，会话控制包的版本和 Skill 摘要核对通过。未调用真实模型或远端主机。

安装验收使用每次独立的目录，避免清理或干扰并行验收；旧证据保留。程序与配置已准备可恢复备份。
