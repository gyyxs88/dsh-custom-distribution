# 升级与回滚

运行安装目录 bin/Update-DSH.ps1 升级。0.4.0 基于 DSH 0.1.5-rc.2，保留旧程序目录；激活前停止 DSH，并将持久数据复制到 data/backups/upgrades 下的独立快照。快照只允许当前用户和 SYSTEM 访问，不读取或输出凭据内容，不会进入 Release。

旧会话由兼容层读取，正式写入时可能升级为新版会话格式。回滚必须同时恢复升级前数据，不能让旧程序直接打开新版日志。

运行 bin/Rollback-DSH.ps1 默认回到上一版本。它要求存在与本次版本切换精确匹配的完整快照；先保留升级后数据到 data/backups/before-restore-*，再恢复升级前数据并切换程序与 profile。升级后的新增会话保留在该备份中，不会合并进旧版历史。缺少快照时拒绝降级，原数据保持不变。

首次安装没有上一版本，也不会伪造回滚成功。文件清理使用 Windows 回收站；目标不支持回收时停止并保留原项。

新电脑安装不迁移旧电脑的数据或认证；跨电脑迁移见 PRIVATE_STATE.md。
