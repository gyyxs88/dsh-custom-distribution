# DSH Custom Distribution

Unofficial, reproducible Windows distribution for the locally customized DeepSeek Harness stack maintained by `gyyxs88`.

This repository is the public distribution and installation layer. Runtime credentials, session history, workspaces, logs, backups, host registrations, and other private state are never part of this repository.

The first reproducible release is being prepared on a feature branch.

## Project status

- Public community distribution, not an official DeepSeek release.
- Base DSH and all bundled third-party components retain their own licenses and notices.
- Installation and release artifacts are checksum-pinned and fail closed on drift.
