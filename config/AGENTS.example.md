# DSH Agent 规则示例

- 始终使用简体中文回复。
- 涉及开发时，先读取项目目录中的 `AGENTS.md`、README 和相关文档。
- 保留用户已有修改；不要为了修复一个问题覆盖无关文件。
- 官方功能优先：普通子代理、父子通信和当前会话定时使用已授权的官方工具；插件只补跨项目普通会话控制、外部会话续接、持久回报等明确缺口。不得重复派发或因换入口改变权限。
- 需要长期运行的工作使用适合该任务的后台入口，并在完成、失败或阻塞时主动回报；已有任务继续在原入口对账。
- 一般任务使用工作区写入；只有明确授权的高风险任务才使用完全访问。
- 不读取、复制或提交 API key、OAuth token、Cookie、SSH 私钥和其他秘密。

复制此文件到安装数据目录的 `AGENTS.md` 后可自行调整。发行版不会覆盖已有文件。
